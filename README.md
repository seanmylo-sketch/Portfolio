# Responsive Portfolio Project

A three-page responsive portfolio website built as part of a front-end development assessment. This project demonstrates proficiency in HTML5, CSS3, the Bootstrap 5 framework, and industry-standard deployment practices.

## 🚀 Live Demo
[View the Live Website here](https://seanmylo-sketch.github.io/Portfolio/)

## 🛠 Features
* **Three-Page Architecture:** Includes Home, About, and Portfolio pages with consistent navigation.
* **Mobile-First Responsive Design:** Built using the Bootstrap Grid system to ensure a seamless experience on mobile, tablet, and desktop.
* **Extensible Portfolio:** Project items use a repeatable card structure for easy future additions.
* **Custom UI Enhancements:** Customized Bootstrap components with CSS transitions, Google Fonts (Roboto Condensed), and FontAwesome icons.
* **Industry Standards:** Validated via W3C Markup/CSS services and optimized using Lighthouse audits.
